사기민팅의 수학적 정의

백킹 행렬의 스펙트럴 반경으로 본 자기참조 백킹 — defi-dagggg / ChainSpiral

토큰을 외생 가격 앵커 \(R\) 와 자가 NAV 파생 \(D\) 로 (오라클 종류로) 나누고, 백킹 행렬 \(A_{ij}=B_{ij}/S_j\) 를 만들었을 때 — 사기 \(\iff \rho(A_{DD}) \ge 1\) (외부로 환원되는 일관 가치의 부재). 사이클의 존재가 아니라 루프 이득이 기준이며, 담보가 움직이면 \(A\) 를 흐름 그래프로 잡는다.

1.백킹을 선형방정식으로

각 토큰 \(i\): 공급 \(S_i\) (온체인), 가격 \(p_i\), 준비금이 보유한 토큰 \(j\) 의 양 \(B_{ij}\) (= balanceOf, 온체인). 값 \(V_i = p_i S_i\).

“토큰 \(i\) 의 가치 = 그 준비금의 가치” 라는 백킹 항등식:

\[ V_i \;=\; \sum_j B_{ij}\,p_j \;=\; \sum_j \frac{B_{ij}}{S_j}\,V_j \qquad\Longrightarrow\qquad \boxed{\,V = A\,V\,}, \quad A_{ij}=\frac{B_{ij}}{S_j} \]
  • \(A_{ij}\) = 토큰 \(j\) 의 총공급 중, \(i\) 의 준비금에 잠긴 비율.
  • 열 합 \(\sum_i A_{ij} \le 1\). 그 누수분 \(1-\sum_i A_{ij}\) = \(j\) 를 실제 외부 홀더가 들고 있는 비율 = “외부로 빠진 진짜 소유”.

2.여기서 오라클이 들어온다 — 앵커 vs 파생

\(V=AV\) 는 누수가 있으면 \(\rho(A)<1\) 이라 유일해가 \(V=0\). 외부 가치 주입(앵커)이 필요. 토큰을 둘로 나눈다:

  • 앵커 \(R\) (외생 가격): 가격이 외부 시장/실물에서 옴. USDC=1, ETH=깊은 시장 오라클. 백킹에서 파생되지 않음.
  • 파생 \(D\) (내생 가격): 가격이 자가 NAV = 준비금가치/공급. \(V=AV\) 가 그대로 적용.
핵심

이 \(R/D\) 분할을 정하는 것이 오라클 종류다. 시장/앵커 오라클 → \(R\). 자가보고 NAV 오라클 → \(D\). (이미 구현한 oracle_introspect 의 anchored/market-feed vs bespoke/NAV 가 정확히 이 분류.)

3.정확한 모순 조건 (= 사기 정의)

파생만 떼어내면:

\[ V_D = A_{DD}\,V_D + A_{DR}\,V_R \quad\Longrightarrow\quad V_D = (I - A_{DD})^{-1}\,A_{DR}\,V_R \]

Perron–Frobenius: \(A_{DD}\ge 0\) 이므로 \((I-A_{DD})^{-1}=\sum_{k\ge0} A_{DD}^{\,k}\). 이것이 유한 양수해로 수렴 \(\iff \rho(A_{DD})<1\).

사기 조건
\[ \rho(A_{DD}) \;\ge\; 1 \quad\Longleftrightarrow\quad \text{외부 앵커로 환원되는 일관 가치가 없음} \;=\; \text{모순(사기)} \]

정도(degree)까지 연속 정량화:

\[ \text{자기팽창 계수} = \frac{1}{1-\rho(A_{DD})}, \qquad \text{외부백킹 비율} \approx 1-\rho \]

\(\rho=0\) → 완전 외부백킹, \(\rho\to1\) → 완전 자기참조(사기 절벽).

4.사이클 ≠ 모순 (루프 이득이 기준)

사이클의 존재가 아니라 사이클의 이득(loop gain)이 기준. 2-사이클 \(i\to j\to i\) 면:

\[ \rho = \sqrt{A_{ij}\,A_{ji}} \]
  • rsETH 루핑: 사이클 있지만 매 패스 LTV<1 해어컷 + 담보가 외부 ETH(앵커) → 이득 < 1 → \(\rho<1\) → 정상 (해어컷 = 누수)
  • 상호백킹 두 토큰이 서로를 전량 준비금으로: \(A_{ij}=A_{ji}=1 \Rightarrow \rho=1\) → 사기. 절반씩이면 \(\rho=0.5\) → 정상.
  • 자기루프 \(A_{ii}\) = (자기 공급 중 자기 준비금에 든 비율). “받은 USDC를 다시 나한테” = \(A_{ii}\to1 \Rightarrow \rho\ge1\).

→ 사이클은 무죄, \(\rho(A_{DD})\ge1\) 이 유죄.

5.오라클의 두 번째 역할 — assertion gap

§3 은 “일관 가치가 존재하나”였고, 별개로 “오라클이 그 가치를 말하나” 도 봐야 한다:

\[ \mathrm{gap}_i = \bigl|\,p_i^{\text{oracle}} - p_i^{\text{backing}}\,\bigr|, \qquad p_i^{\text{backing}} = \frac{\sum_j B_{ij}\,p_j}{S_i} \]

\(\rho<1\) 이라 일관해가 있어도, 하드코딩/동결 오라클이 \(p^{\text{backing}}\) 과 다른 값을 주장하면 그 자체가 모순(가격 동결 → 청산 미발화 → bad debt 누적). risk-exposure 의 oracle_hardcoded_switch 가 이 축.

6.정적(stock) vs 흐름(flow) — xUSD 는 흐름이 필요

  • Stock \(B_{ij}\) (현재 balanceOf): 상호백킹·자기보유를 잡음. 한 스냅샷.
  • xUSD 함정: 받은 USDC 를 빼서 재예치 → 스냅샷엔 USDC 가 안 보일 수 있음. 흐름 현상.
  • Flow 그래프: 노드=주소/토큰, 엣지=mint 를 펀딩한 담보의 출처. 발행자 통제집합 \(S\) 가 flow-SCC 를 이루고, 그 SCC 의 순외부유입 ≈ 0 인데 발행 > 0 → 그 블록 \(\rho\ge1\).

흐름 보존형(동치):

\[ \text{사기} \iff \sum_{i\in S} S_i\cdot\text{peg} \;>\; \underbrace{\bigl(\text{$S$ 밖에서 $S$ 로 들어온 누적 외부유입}\bigr)}_{\text{재활용은 cycle 이라 } 0 \text{ 에 수렴}} \]

“내가 받은 걸 나한테 다시” = \(S\) 내부 사이클 → 우변 \(0\) → 위반. 이것이 flow_trace.py 가 보는 것.

8.온체인 측정 가능성 + 정직한 판단점

측정 가능 (HIGH): \(S_i\) (totalSupply), \(B_{ij}\) (balanceOf), flow (mint 로그 + 담보 출처), 오라클 종류 (introspection).

진짜 어려운 곳 (여기가 전부를 가른다)

  • 누가 앵커 \(R\) 인가 — “시장가 있음”이 곧 외생은 아님(LUNA). 깊이/독립성(CAPO 식) 검증이 \(R\) 자격의 핵심. \(R\) 오분류 = 유일한 치명적 실패모드.
  • 발행자 집합 \(S\) 식별 — flow-SCC(독립 외부유입 없는 닫힌 성분)로 검출, 임계 필요.
  • 단위/decimals/peg 정합.

9.앵커의 backing 은 어디 있나 — RWA / off-chain 처리

“USDC 의 백킹(실물 달러)은 off-chain 인데 \(A\) 에 안 들어가지 않나?” — 정확한 의문. 셋으로 분리해 답한다.

(a) USDC 의 on-chain 보유분은 이미 방정식에 있다

D-토큰 \(i\) 가 준비금에 들고 있는 USDC 는 앵커 주입 항 \(A_{DR}V_R\) 로 들어간다:

\[ V_D = (I-A_{DD})^{-1}\,\underbrace{A_{DR}V_R}_{\text{앵커(USDC 등)에서 들어온 가치}} \]

\(i\) 는 자기가 온체인으로 실제 보유한 USDC 만큼만 백킹 크레딧을 받는다 (\(A_{i,\text{USDC}}=B_{i,\text{USDC}}/S_{\text{USDC}}\)). “은행에 USDC 있다”는 off-chain 주장은 \(B=0\) 이라 자동으로 0 크레딧 — 오히려 robust.

(b) 방정식 밖에 있는 것 = \(p_{\text{USDC}}=1\) 의 정당성

들어가지 않는 건 USDC 보유량이 아니라 그 가격이 1 이라는 보장(= off-chain 준비금)이다. 이건 환원 불가능한 신뢰 공리. 모든 온체인-only 시스템은 어떤 외생 공리에서 멈춘다. \(R\) = 공리 집합 = 신뢰 경계. 프레임워크는 “\(R\) 이 건전하다면 \(D\) 가 일관되나”라는 상대적 일관성만 증명한다 (공리 대비 정리).

(c) 고치는 법 — \(R\) 을 계층화 + off-chain 노드 명시

앵커는 한 종류가 아니다. \(R\) 을 종단(terminal) 종류로 쪼갠다:

앵커 종류예backing 위치신뢰
\(R_{\text{chain}}\) — 온체인 본원ETH, (native), stETH온체인 / 프로토콜 강제 상환HIGH
\(R_{\text{rwa}}\) — off-chain 실물USDC, USDT, USYC, T-bill 토큰off-chain 준비금 → attestation 엣지로 노드 \(\Omega\) 연결 (weight 검증불가)MEDIUM
market-only — 시장가만상환 없는 토큰외부 시장 (깊이 검증 필요, LUNA 함정)LOW

그러면 각 D-토큰의 grounded value 가 백킹 경로의 종단별로 분해된다:

\[ V_i \;=\; V_i^{\text{chain}} \;+\; V_i^{\text{rwa}} \;+\; V_i^{\text{mkt}} \qquad (\text{경로가 어느 } R\text{ 에서 끝나는가}) \]

“이 토큰 가치의 \(X\%\) 는 온체인 증명, \(Y\%\) 는 RWA attestation, \(Z\%\) 는 시장가” — 이게 정직한 출력. 신뢰도는 support 의 최약 앵커로 캡: \(\;\mathrm{conf}(i)=\min_{a\in\text{support}(i)} \mathrm{conf}(a)\).

(d) 앵커 자체가 무너지면? — 탐지가 아니라 시나리오

USDC 디페그/준비금 가짜는 off-chain 이라 온체인으로 탐지 불가. 대신 노출도를 정량화: 특정 앵커에 충격 \(\delta\) 를 주고 재계산.

\[ V_D(\delta) = (I-A_{DD})^{-1}A_{DR}\,(V_R-\delta) \]

= “USDC 가 \(\delta\) 만큼 무너지면 D 가 얼마 잃나” (risk-exposure 의 스트레스-테스트 영역). 자기참조 탐지(\(\rho\ge1\), 온체인) 와 앵커-실패 노출(\(V_R\) 시나리오) 는 별개의 질문.

정리

프레임워크의 일은 모든 가치를 최소한의 명시적 외생 신뢰 공리로 밀어내리는 것. 건강한 토큰 = 소수의 고품질 앵커에 얕게 의존. 사기 = \(\rho\ge1\) (grounding 없음) 또는 grounding 이 순환/가짜 앵커에 전부 의존. off-chain proof-of-reserves(DD)는 정확히 이 \(R_{\text{rwa}}\) 노드에서 인계받는다 — 프레임워크가 “무엇을 off-chain 으로 신뢰해야 하는지”를 정확히 짚어준다.

한 줄 정의

토큰을 외생 앵커 \(R\) 과 자가 NAV 파생 \(D\) 로 (오라클 종류로) 나누고, 백킹 행렬 \(A_{ij}=B_{ij}/S_j\) 를 만들었을 때 — 사기 = \(\rho(A_{DD})\ge1\) (외부로 환원되는 일관 가치 부재). 사이클이 아니라 루프 이득이 기준이고, 담보가 움직이면 \(A\) 를 흐름 그래프로 잡는다. 정도는 \(\dfrac{1}{1-\rho}\) 로 연속 정량화.
